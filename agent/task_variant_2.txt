— Количество одновременных сессий = 3;
— Лимит логических чтений за сессию = 130000;
— Лимит CPU на вызов = 6500;
— Время соединения = 80 минут;
— Срок действия пароля = 28 дней;
— Льготный период после истечения пароля = 4 дня.
Создайте роль CTF_ROLE с паролем ctf_role.
Создайте пользователя CTF_STUDENT с паролем ctf_student со следующими параметрами:
— Табличное пространство по умолчанию: CTF_TABLESPACE;
— Временное табличное пространство: TEMP;
— Квота на использование CTF_TABLESPACE: 260 МБ;

— Учётная запись разблокирована.
