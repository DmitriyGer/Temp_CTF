Разблокируйте пользователя compromised_user.
Получите учётные данные из таблицы credentials и выполните вход под ними.
Создайте табличное пространство объёмом 560 МБ с авторасширением и верхним пределом 1 ГБ. Назовите его CTF_TABLESPACE.
Создайте профиль CTF_PROFILE со следующими ограничениями:
— Время простоя сессии = 20 минут;
— Лимит логических чтений на вызов = 11000;
— Лимит CPU на сессию = 32000;
— Число неудачных попыток входа до блокировки = 3;
— Время блокировки учётной записи = 1 день;
— Количество одновременных сессий = 2.
Создайте роль CTF_ROLE с паролем ctf_role.
Создайте пользователя CTF_STUDENT с паролем ctf_student со следующими параметрами:
— Табличное пространство по умолчанию: CTF_TABLESPACE;
— Временное табличное пространство: TEMP;
— Квота на использование CTF_TABLESPACE: 280 МБ;
— Профиль: CTF_PROFILE;
— Учётная запись разблокирована.
Выдайте пользователю минимальные привилегии для подключения к базе данных.
Назначьте ему роль CTF_ROLE без установки её по умолчанию.
Предоставьте через эту роль право выборки данных из объекта CTF.CTF_FLAG.
Под пользователем CTF_STUDENT активируйте роль с использованием её пароля и получите флаг из объекта CTF.CTF_FLAG.
